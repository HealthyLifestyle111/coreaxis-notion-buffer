# CoreAxis — ManyChat Master Funnel Production

Status: PRODUCTION BUILD / CAMPAIGNS OFF EXCEPT EXPLICIT LAUNCH

## Governing model
Traffic from Instagram, TikTok, Facebook, YouTube, X, LinkedIn, Pinterest, website, paid ads, referrals and email enters the CoreAxis acquisition system. ManyChat is the conversation and conversion layer wherever native channel support exists. Non-native traffic uses tracked CTAs into a ManyChat-compatible entry point or the appropriate owned destination. Zapier is the automation plumbing. Whole Practice is the practitioner/client environment. Wix is the owned website/shop/digital-product destination.

## Universal routing
1. Identify intent.
2. Preserve direct-access exceptions.
3. If the person already knows they want EllieMD/peptide support, route directly to the approved EllieMD path.
4. If the person already wants CellCore/JumpStart, route directly to the approved CellCore path.
5. Otherwise run Core Access elimination.
6. Return ONE best starting pathway, not a menu of seven.

## Digital product model
For e-books/guides: content -> keyword/CTA -> ManyChat -> resource/product destination -> follow-up -> relevant CoreAxis pathway when appropriate. Wix remains the owned storefront; do not add Shopify/Etsy unless a later strategic requirement exists.

## Lead magnets
Reusable families: menopause, whole-woman wellness, fertility/preconception, men's vitality, pet wellness, cellular wellness, peptides. Each requires asset, trigger, delivery, qualification, route, follow-up.

## Platform strategy
Native ManyChat channels are used for direct conversation. Other platforms remain acquisition/distribution channels and feed tracked CTAs, website destinations, or supported conversation entry points. Do not force unsupported native integrations.

## Zapier contract
ManyChat event -> identify/create/update lead -> preserve source/campaign/intent/route -> Whole Practice or appropriate destination -> notification where needed -> conversion event -> suppression/update. Prevent duplicate records.

## Safety/compliance routing
Automation must not diagnose, guarantee outcomes, invent protocols/products, or provide practitioner-level individualized clinical conclusions. Route complex/clinical questions to human review. After conversion, stop acquisition messaging.

## QA matrix
Test each live campaign through: trigger -> conversation -> qualification -> route -> destination -> downstream record -> notification -> follow-up -> suppression. Include direct-access, uncertain, existing-client, no-response, duplicate, high-intent, and practitioner-handoff cases.

## Launch control
Only explicitly activated campaigns go live. All other campaign automations remain OFF/ready. EllieMD is the current launch candidate. Master architecture is reusable across future campaigns.
